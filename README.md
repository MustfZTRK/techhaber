# TechHaber — Teknoloji Haber Platformu

> GitHub: https://github.com/MustfZTRK/techhaber

## 🇹🇷 Türkçe

RSS ile beslenen, PHP görünüm + Node toplayıcı içeren teknoloji haber platformu.

### Özellikler
- RSS toplama (rss.js)
- PHP haber görünümü
- Zamanlanmış içerik (creator.js)

### Kurulum
```bash
npm install
```

> Not: Gerçek API anahtarları/şifreler repoya **dahil değildir**. `.env.example` dosyasını `.env` olarak kopyalayıp kendi değerlerinizi yazın.

### Kullanım
```bash
npm start
```

---

## 🇬🇧 English

Tech news platform fed by RSS, with PHP views + Node collector.

### Features
- RSS collection
- PHP news view
- Scheduled content

### Installation
```bash
npm install
```

> Note: Real API keys/passwords are **not** included. Copy `.env.example` to `.env` and fill in your own values.

### Usage
```bash
npm start
```
